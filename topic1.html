On-Page SEO

On-page SEO refers to the optimizations made directly on a webpage — its content, structure, and HTML — to help search engines understand what the page is about and help visitors find what they are looking for. Unlike technical SEO (which focuses on server and site-level settings), on-page SEO is about the words, headings, images, and links that appear on the page itself.

Headings and Content Structure

Every page should start with a single main heading (<h1>) that clearly identifies the topic. Subheadings (<h2>, <h3>) organize the content into logical sections. A clear heading hierarchy helps both users and search engines scan and understand the page.

  • Use only one <h1> per page
  • Keep headings descriptive and meaningful
  • Do not skip heading levels (e.g. h1 → h3)

Keywords and Search Intent

Keywords are the words and phrases users type into a search engine. Good on-page SEO identifies the primary keyword for each page and uses it naturally in the title, first heading, and early paragraphs.

  • Write for the reader first, search engines second
  • Avoid "keyword stuffing" — forced repetition hurts readability
  • Include related terms to build topical depth

Title Tags and Meta Descriptions

The <title> tag appears in search results and browser tabs. The meta description provides a brief summary shown under the title in search results. Neither directly controls rankings, but both influence click-through rates.

  • Keep titles under 60 characters
  • Write meta descriptions of 150–160 characters
  • Make each page's title and description unique

Images and Alt Text

Images support the content and improve user engagement. The alt attribute describes the image for screen readers and for search engine crawlers that cannot "see" images.

  • Write concise, descriptive alt text
  • Avoid phrases like "image of" or "picture of"
  • Keep decorative images with empty alt (alt="")

Internal Links and Navigation

Internal links connect related pages within the same site. They help users discover more content and help search engines understand how pages are related to each other.

  • Use descriptive anchor text instead of "click here"
  • Link to related pages when it benefits the reader
  • Ensure every page is reachable from the main navigation

URL Structure

Clean, readable URLs help users understand where they are on a site. Short, descriptive URLs are easier to share and are preferred by search engines.

  • Use lowercase letters and hyphens between words
  • Keep URLs short and descriptive (e.g., /on-page-seo)
  • Avoid unnecessary parameters or numbers in URLs
